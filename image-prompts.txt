DETAILRESUME DECK — IMAGE PROMPTS
=================================

How to use
----------
1. Generate each image with the prompt below (Midjourney, DALL·E, Imagen, Flux, Firefly, etc.).
2. Save it into  public/images/  using the suggested file name.
3. Set the path in  src/deck.config.ts  → images, e.g.  arjunAvatar: '/images/arjun.jpg'
   Any slot left as '' keeps showing the dashed placeholder.

Brand colours to mention if your tool supports it: primary blue #0665FE, deep blue #0A3FDF,
off-white #F6F6F4, charcoal #3A3A3A. Keep images clean, modern and uncluttered — the deck
uses lots of white space and a single bright blue accent.

4) QR CODE — DONE: public/images/qr.png already points to https://www.detailresume.com
   Slide 14 "Beat the ATS"  ·  config key: qrCode  ·  file: qr.png
   Shown at 368 × 368 on a white card.
-----------------------------------------------------------------------------------------

Do NOT use an AI image generator for this — AI-made QR codes usually don't scan.
Create it with any QR generator (e.g. your browser's "Create QR code for this page",
qr-code-generator.com, or the `qrcode` npm package):
  - URL: https://detailresume.com  (add UTM tags if you want to track scans,
    e.g. ?utm_source=marwadi&utm_medium=talk)
  - Foreground colour: #0A3FDF or black · Background: white
  - Export as PNG at least 1000 × 1000 px with a small quiet-zone margin.
  - Test it with two different phones before the talk.
